# Code of Conduct

This project follows the spirit of the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our standards

Be respectful and constructive in issues, pull requests, discussions and reviews. Assume good
faith, critique ideas rather than people, and accept that maintainers may decline changes.

Not acceptable: harassment, personal attacks, discriminatory language, publishing someone's private
information, and sustained disruption. Because Warden is a security tool, sharing live malware,
working exploits against third parties, or real credentials is also not acceptable — describe
detections with defanged indicators instead.

## Scope

This applies in every project space (the repository, issues, discussions and pull requests) and
when you represent the project elsewhere.

## Enforcement

Report conduct problems privately to the maintainer, [@rakshit-737](https://github.com/rakshit-737),
for example through a private security advisory if nothing else fits. Reports are handled
confidentially. The maintainer may edit or remove contributions, and warn, temporarily restrict or
permanently ban contributors whose behaviour is not in line with this code.
